## OVERVIEW

AethelDesk is a small shared-room productivity dashboard: FastAPI owns room state, PIN auth, Redis, WebSockets, and static serving; Vite + vanilla ES modules own the browser lobby and room UI.

## STRUCTURE

```text
backend/             # FastAPI app, state reducer, Redis room store, WebSocket sync
frontend/            # Vite multi-page vanilla JS UI; lobby and room entries
tests/               # pytest contracts plus Playwright e2e
docs/architecture/   # public route, Redis, WebSocket, storage contracts
docs/ux/             # accessibility, reduced-motion, Korean-copy audit/handoff
docker/redis/        # Redis AOF config used by Compose
```

## CONVENTIONS

- Python targets 3.12. Ruff checks `E`/`F`; line length is 120 and `E501` is ignored.
- Pyright type checking is `basic` and covers only `backend` and `tests`.
- Frontend is Vite + vanilla ES modules. `vite.config.js` sets `root: "frontend"` and proxies `/api` and `/ws` to backend port `8000`.
- Runtime CSS is local under `frontend/styles/`; Google Fonts and Tailwind CDN are not allowed runtime dependencies.
- `pyproject.toml` + `uv.lock` are authoritative for Python dependencies. `requirements*.txt` are compatibility exports.
- `package.json` + `package-lock.json` are authoritative for frontend dependencies.
- `frontend/dist/` is generated by `npm run build`; do not edit or commit it unless a release process explicitly asks.
- Several backend files keep package imports plus `ModuleNotFoundError` fallback for script-mode/container startup; preserve that unless startup changes.

## ANTI-PATTERNS (THIS PROJECT)

- Do not introduce React, Vue, Svelte, TypeScript, Webpack, SQL/accounts/analytics, Redis Streams, Celery, Kubernetes, TLS automation, or reverse-proxy config without separate approval.
- Do not store plaintext PINs or token hashes in API responses, URLs, `localStorage`, or Redis plaintext values; opaque room tokens belong only in create/join responses and `sessionStorage`.
- Do not change Redis key/channel names, WebSocket close codes `1008`/`1011`, `BackendState`, or frontend storage keys without contract tests and an explicit decision update.
- Do not weaken Korean-primary UI policy; keep `AethelDesk`, `PIN`, YouTube terms, API fields, routes, and storage keys stable.
- Do not treat in-memory room state as production behavior; Redis is mandatory for Docker/prod and cross-worker sync.

## UNIQUE STYLES

- User-visible controls, validation, live regions, and status copy are Korean-primary.
- Full-state room snapshots are favored over deltas across WebSocket and Redis Pub/Sub.
- Auth failures intentionally avoid revealing whether the room, PIN, or token was wrong.
- Browser a11y behavior is contractual: labels, live regions, hidden-control tab order, dialogs, reduced motion, and hidden YouTube iframe attributes are covered by tests.

## NOTES

- Default `pytest` excludes `tests/e2e` through `pytest.ini`.
- E2E starts uvicorn from `backend/` in test mode and uses a random local port.
- Docker Compose uses Redis AOF config in `docker/redis/redis.conf`; Docker may be unavailable in this workspace even when CI can run it.
- Local task evidence often lives in `.omo/evidence/`; do not commit it unless the orchestrator asks.
