# Aethel Astrarium concept references

These AI-generated reference sheets guided the code-native Three.js reward model:

- `aethel-astrarium-single-reference.png` defines the hero silhouette, navy enamel core, antique-brass armillary rings, and four amber reward nodes.
- `aethel-astrarium-reference.png` adds front, side, and three-quarter construction views for spatial proportions.

The production model does not ship either image as a runtime texture. Its geometry, materials, progress states, animation, and disposal lifecycle are implemented in `frontend/src/3d/reward-constellation.js`.
